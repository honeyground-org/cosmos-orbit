Command reference

Use --home PATH (or HARNESS_HOME) consistently for hooks, worker and observers. Viewing help, briefs or the dashboard never starts model work; the only model call after a claim is the one review.

Your own session (hooks)

cosmos-orbit hooks install

Add the hooks (SessionStart, UserPromptSubmit, Stop, PreCompact, and SessionEnd for Claude Code) once. Inert until something is switched on.

cosmos-orbit on --global · cosmos-orbit on · export ORBIT=on

Three scopes, each with off: every project (--global), this project (Git root), this terminal session (environment). Precedence: terminal → project → global → off. Stored switches persist.

cosmos-orbit context [200k | on | off] [--global] · export ORBIT_HANDOFF_AT=250k

Mid-task handoff point, same three scopes as on/off (default 200k, measured). Without a value: the point and the live context here.

cosmos-orbit settings

Hook installation, switches, handoff points and what applies in this folder.

claude --dangerously-skip-permissions · codex

Your normal command. The first substantial prompt becomes the goal; every prompt, correction, evidence and verdict lands in the ledger; the brief returns after compaction and at the next session.

Inside the session (the executor calls these)

cosmos-orbit done TASK_ID 'D1 …' [--add] [--keep] [--check ARGV_JSON]

Write a revision of the result goals and verification goals. Required after every requirement change before a claim; fixed checks are append-only.

cosmos-orbit evidence TASK_ID D1 --note '…' [--command '["python3","-m","pytest"]'] [--file path]

Evidence per item: a command actually run (exit code and output tail), a file fingerprint, or a note.

cosmos-orbit checkpoint TASK_ID --next '…' [--notes '…'] [--file path]

At the handoff point: the next step and what the ledger cannot know. The user then types /clear or /new; the fresh session starts from it.

cosmos-orbit claim TASK_ID --summary '…' [--remaining '…'] [--wait]

Completion claim: fixed checks run now; a failure returns to you; a pass queues one independent read-only review.

cosmos-orbit feedback TASK_ID "Correction"

Keep the original goal and add this correction. Repeated --done explicitly replaces the checklist.

cosmos-orbit brief [TASK_ID]

Print what the hooks inject: goal, corrections, checklist, evidence, last verdict, stop reason.

cosmos-orbit handoff TASK_ID --write docs/HANDOFF.md

Render the ledger as a Markdown handoff. Nothing is written by hand.

Unattended (private clone)

cosmos-orbit start --provider codex --workspace /path/to/repo "Your request"

Fix the goal, execute with the native CLI in an isolated clone, run fixed checks and independently test the completion claim.

cosmos-orbit worker --background

Continue authorised queued work, pending reviews and interrupted calls after the terminal closes.

cosmos-orbit resume TASK_ID · cosmos-orbit pause TASK_ID

Continue after a pause, or stop at a safe boundary. A user pause is never cleared by recovery.

Inspect

cosmos-orbit dashboard

The same goals, evidence, checks, reviews and stop reasons as the terminal, for both entrances.

cosmos-orbit watch --once · cosmos-orbit status TASK_ID

One model-free snapshot, or the full record of one task.

cosmos-orbit verify TASK_ID

Recheck a claimed result now: fixed checks plus one independent review. Missing evidence is not completion.

cosmos-orbit lessons

Corrections repeated across tasks: candidates for a guard rule, counted from the ledger.

cosmos-orbit evolve · cosmos-orbit evolve --reset-learned

What this installation learned locally from the executor's decisions (never in the code), or forget it.
